# Экономическая проверка — 28.09.2026

Доказанной экономии относительно реального пакетного тура пока нет. Демонстрационные суммы MOCK / SYNTHETIC / bookable:false видны как учебный ориентир в карточках, отдельной строке сравнения и деталях. Они исключены из фактического расчёта поездки и не участвуют в выводах об экономии.

## Какие суммы допустимы

Только цена выбранного реального предложения после проверки дат, аэропортов, взрослых, возраста каждого ребёнка, размещения, питания, багажа, обязательных сборов и доступности. Пользователь вносит полную сумму в RUB, ссылку и описание. Метки: DEEPLINK / REAL по подтверждению пользователя / bookable:unknown / evidence:USER_REPORTED. Это не подтверждение цены API и не гарантия бронирования.

Внешние публичные страницы могут показывать реальные розничные цены. Присутствие параметров в URL само по себе не подтверждает цену или наличие мест. Наблюдаемый минимум учитывается отдельно как LIMITED_REAL / PUBLIC_PAGE_OBSERVED с RUB, источником и временем; он не считается проверенным семейным тарифом и не завершает расчёт поездки.

Это разные тарифные условия; нельзя автоматически добавлять модельный багаж к минимуму и обещать полученную сумму.

Автоматическое обновление цены не подключено. Точные возраста детей (5/7/9), багаж, пересадки, аэропорт возвращения, продавец и условия отмены не подтверждены. Короткая авиассылка передаёт категории детей, но не их точные возраста.

Статус: DEEPLINK / LIMITED_REAL / bookable:unknown / PUBLIC_PAGE_OBSERVED. Это только промежуточная сумма перелёта. Вариант не признан доступным для бронирования или более дешёвым, чем реальный пакет. Проживание, трансферы и прочие обязательные расходы остаются неизвестными.

Суммы 96 700 RUB за перелёт и 112 442 RUB за гостиницу из прежних деталей были синтетическими. Валюта была RUB; причина разницы — отсутствие тарифа Aviasales в формульной модели, а не подтверждённая ошибка конвертации.

Для полного тура дополнительно фиксируются оператор и его страна, реальный отель, тип номера, питание, включение перелётов и проживания, условия продажи туристам и способ оплаты. Заграничная цена вводится в RUB после проверки курса и комиссий; исходная валюта, курс и комиссии описываются пользователем. Автоматического валютного расчёта нет.

В пакет не добавляются повторно включённые услуги. Для включённой дополнительной услуги допустима строка 0 с источником и пояснением; неизвестная стоимость остаётся незаполненной. Пакет за 0 не принимается.

Полная поездка через gateway = пакеты всех номеров/групп + дорога до gateway туда/обратно + не включённые ночёвки, питание, трансферы, багаж, визы, налоги, страховки и платёжные расходы. Пока есть незаполненные строки или ошибки дат/occupancy, показана промежуточная сумма.

## Ограничения сравнения

- Реальных тарифов пакетных туров из API в этой версии нет; выбранный тур можно учесть вручную с доказательствами.
- Суммы sandbox/demo/mock, средние цены, рекламные «от», цена на двоих вместо семьи, отель без перелёта вместо тура не являются сопоставимой полной ценой.
- Карточка показывает стоимость из внесённых источников, если она есть; при отсутствии источника виден учебный SYNTHETIC-расчёт. Сравнение держит их в разных строках. Сортировка по фактической цене допустима только между полными расчётами. Автоматического заявления об экономии нет.
- Перед выводом об экономии нужны реальные полные суммы обоих вариантов для одной семьи, совпадающих сроков, размещения и состава услуг.
